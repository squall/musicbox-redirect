# musicbox.seerinn.com 轉址

App「Share MusicBox」已更名為「口袋唱片 PocketDisc」，網站搬到 https://pocketdisc.seerinn.com/ 。
App Store 1.0 版的隱私權政策與支援網址仍指向舊網址，這個 repo 讓舊網址自動轉到新網址（保留路徑）。

- `/` → https://pocketdisc.seerinn.com/
- `/privacy.html` → https://pocketdisc.seerinn.com/privacy.html
- 其他路徑（404.html）→ 新網域的同一路徑

請勿刪除：只要還有舊版 App 或舊連結在外流通，就需要保留。
